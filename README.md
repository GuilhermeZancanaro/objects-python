# objects-python
Academic exercises and activities focused on objects and Object-Oriented Programming using Python.

A collection of academic exercises and activities developed in Python to practice working with objects and Object-Oriented Programming (OOP).<br>

The activities were created as part of my programming studies, focusing on creating classes, objects, attributes, methods, and understanding the fundamentals of object-oriented programming.<br>

About the Project<br>

This repository contains exercises involving Python classes and objects, exploring different concepts of Object-Oriented Programming.<br>

The goal is to develop a better understanding of how objects can be created and used to represent entities and organize code in Python.<br>
